# Trickle

Expense tracker web app: upload bank statements (HDFC and most banks — CSV, Delimited or Excel), track budgets, and share trip expenses live with friends.

Live: https://firstlaboratory.github.io/expenses/

- `index.html`, `app.js` — the app (no build step)
- `firebase-config.js` — Firebase project config (sign-in + sync)
- `firestore.rules` — security rules; paste into Firebase console → Firestore → Rules
- `sw.js`, `manifest.json`, icons — installable/offline support
